# Pokémon Language Adventure: Lingua Region

A Pokémon-inspired educational RPG Digital Learning Object (DLO) designed for **Year 4 Bahasa Melayu** students aligned with **KSSR DSKP Standard Content 5.2** (*Memahami dan menggunakan pembentukan kata mengikut konteks*).

## Features
- **3 Learning Regions + Champion League**:
  - **Region 01: Grassland Forest** (Gym Leader Flora) — *Kata Berimbuhan* (Awalan, Akhiran, Apitan)
  - **Region 02: Metro City** (Gym Leader Volt) — *Kata Majmuk* (Bebas & Mantap)
  - **Region 03: Mountain Cave** (Gym Leader Rocky) — *Kata Ganda* (Penuh & Separa)
  - **Champion League** — Team Rocket Boss & Language Champion Final Examination
- **Multiple Gameplay Modes**: Wild Pokémon Encounters, Catching Challenges, Trainer & Gym Battles, Word Puzzle Builder, Hidden Item Exploration, and Pokémon Center Revision.
- **Full RPG Mechanics**: Turn-based grammar battles, HP & XP progression, Pokémon evolution, 6-slot active party, Pokédex + Bahasa Melayu Learning Dex, Item Shop, Achievements, and Professor Bahasa Assistant.
- **100% Static & Offline-Ready**: Built with HTML5, CSS3, and Vanilla JavaScript with Web Audio synthesis, custom SVG sprites, and LocalStorage save management.

## Deployment on GitHub Pages
1. Upload all files maintaining the exact folder structure (`index.html`, `css/`, `js/`).
2. Go to **Settings > Pages** in your GitHub repository.
3. Under **Source**, select `Deploy from a branch`, choose `main` (root `/`), and click **Save**.
